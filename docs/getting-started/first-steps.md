# First Steps

## Creating Your Account

1. Navigate to the registration page
2. Enter your email and password
3. Complete your profile information
4. Verify your email address

## Creating Your First Workspace

1. Click "New Workspace" in the sidebar
2. Enter a name for your workspace
3. Invite team members by email
4. Set up your workspace settings

## Creating Your First Project

1. Navigate to the Projects section
2. Click "New Project"
3. Enter a project name and description
4. Choose a color and icon

## Creating Your First Task

1. Navigate to the Tasks section
2. Click "New Task"
3. Enter a task title and description
4. Assign the task to a team member
5. Set priority and due date

## Organizing Your Work

### Kanban View

- Drag and drop tasks between columns
- Columns represent task status (TODO, IN_PROGRESS, IN_REVIEW, DONE)
- Use filters to focus on specific tasks

### List View

- Sort tasks by priority, due date, or assignee
- Use quick filters to find specific tasks
- Bulk edit multiple tasks

## Collaborating with Your Team

1. Invite members via Workspace Settings > Team
2. Assign tasks by clicking the assignee icon
3. Add comments to discuss tasks
4. Use mentions (@) to notify specific team members

## Taking Notes

1. Navigate to the Notes section
2. Click "New Note"
3. Use the block editor to add content
4. Organize notes by project or category

## Managing Your Calendar

1. Navigate to the Calendar section
2. Click "New Event"
3. Enter event details (title, time, location)
4. Invite attendees from your workspace
