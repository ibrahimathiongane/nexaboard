# Workspace Setup

## Creating a Workspace

1. Click "New Workspace" in the sidebar
2. Enter a workspace name (e.g., "Marketing Team")
3. Add a description (optional)
4. Click "Create"

## Managing Members

### Adding Members

1. Go to Workspace Settings > Team
2. Click "Invite Member"
3. Enter the member's email address
4. Select their role (Admin, Member, or Viewer)
5. Click "Send Invite"

### Member Roles

- **Owner**: Full access, can delete workspace
- **Admin**: Can manage settings and members
- **Member**: Can create and edit content
- **Viewer**: Read-only access

### Removing Members

1. Go to Workspace Settings > Team
2. Find the member you want to remove
3. Click the menu icon (...)
4. Select "Remove from Workspace"

## Workspace Settings

### General Settings

- **Name**: Workspace display name
- **Description**: Brief description of the workspace
- **Slug**: URL-friendly identifier

### Permissions

- **Who can create projects**: Owners, Admins, or everyone
- **Who can manage members**: Owners and Admins only
- **Who can delete content**: Depends on role

## Best Practices

1. **Organize by team or department**: Create separate workspaces for different teams
2. **Use consistent naming**: Keep workspace names clear and descriptive
3. **Set clear roles**: Assign appropriate permissions to members
4. **Regular cleanup**: Archive or remove inactive workspaces
