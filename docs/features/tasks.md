# Tasks

## Overview

Tasks are the core unit of work in nexaBoard. They represent actionable items that need to be completed.

## Creating Tasks

1. Navigate to the Tasks section
2. Click "New Task"
3. Fill in the task details:
   - **Title**: Brief description of the task
   - **Description**: Detailed information
   - **Status**: TODO, IN_PROGRESS, IN_REVIEW, or DONE
   - **Priority**: URGENT, HIGH, MEDIUM, or LOW
   - **Assignee**: Team member responsible
   - **Due Date**: When the task should be completed
   - **Labels**: Tags for categorization

## Managing Tasks

### Kanban View

- Drag tasks between columns to update status
- Click a task to view details
- Use the menu for more options

### List View

- Sort by priority, due date, or assignee
- Filter by status, priority, or assignee
- Bulk edit multiple tasks

### Task Details

- **Subtasks**: Break down complex tasks
- **Comments**: Discuss progress with team
- **Attachments**: Add relevant files
- **Time Tracking**: Log time spent

## Task Dependencies

- Block tasks that depend on others
- Visualize dependencies in the task view
- Automatic status updates when dependencies complete

## Best Practices

1. **Keep titles clear**: Use action-oriented titles
2. **Set realistic deadlines**: Consider team capacity
3. **Use labels consistently**: Create a labeling system
4. **Regular updates**: Keep task status current
5. **Break down large tasks**: Use subtasks for complex work
