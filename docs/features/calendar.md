# Calendar

## Overview

The calendar helps you schedule and manage events, meetings, and deadlines with your team.

## Creating Events

1. Navigate to the Calendar section
2. Click "New Event"
3. Fill in event details:
   - **Title**: Event name
   - **Description**: Additional details
   - **Date/Time**: When the event occurs
   - **Duration**: How long it lasts
   - **Location**: Where it takes place
   - **Color**: Visual categorization

## Event Types

### One-Time Events

- Single occurrences at specific times
- Perfect for meetings and appointments

### Recurring Events

- Repeat on a schedule (daily, weekly, monthly)
- Automatically create future instances

### All-Day Events

- Span entire days
- Great for deadlines or milestones

## Managing Events

### View Options

- **Month**: See entire month at a glance
- **Week**: Detailed weekly view
- **Day**: Focus on single day

### Event Actions

- **Edit**: Update event details
- **Delete**: Remove events
- **Duplicate**: Create copies of events
- **Link to Task**: Connect events to tasks

## Team Calendar

- See all team members' events
- Identify scheduling conflicts
- Plan team meetings effectively

## Best Practices

1. **Use colors consistently**: Create a color coding system
2. **Set reminders**: Get notified before events
3. **Include location**: Add meeting rooms or video links
4. **Keep descriptions brief**: Focus on essential details
5. **Regular review**: Check calendar daily for upcoming events
