# nexaBoard Documentation

## Overview

nexaBoard is a productivity application designed for small teams (5-20 members). It provides task management, note-taking, calendar, and project management features.

- [First Steps](getting-started/first-steps.md)

- [API Documentation](api/authentication.md)

## Features

- **Task Management**: Create, assign, and track tasks with Kanban and list views
- **Notes**: Collaborative note-taking with rich content blocks
- **Calendar**: Schedule and manage events with team visibility
- **Projects**: Organize work into projects within workspaces
- **Workspaces**: Team collaboration spaces with role-based access
